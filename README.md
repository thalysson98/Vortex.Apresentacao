# Vortex Integration — Apresentação Interativa

Apresentação comercial e técnica interativa do **Vortex Integration**, suplemento integrado ao SolidWorks para automação de dados, gestão de estruturas e conexão com ERP.

## Acesso Online

Este repositório está configurado para publicação direta via **GitHub Pages**.

Ao ativar o GitHub Pages nas configurações do repositório (`Settings > Pages > Deploy from a branch > main / root`), a apresentação fica disponível publicamente em:

`https://<seu-usuario>.github.io/Vortex.Apresentacao/`
